# ArmDesk

[English version](README.md)

ArmDesk это форк клиента удалённого рабочего стола
[RustDesk](https://github.com/rustdesk/rustdesk). Его собирает ИТ-студия
[ARMILEN](https://www.armilen.ru) для поддержки своих клиентов. Клиент заранее
настроен на наши серверы и выходит под нашим именем. Сборка независимая:
проект RustDesk с ней не связан и её не одобрял.

## Где скачать

Установщики для Windows, macOS, Linux и Android лежат на
https://www.armilen.ru/support. Те же файлы приложены к
[релизам](../../releases) этого репозитория.

## Отличия от RustDesk

- Своё имя, значки, логотипы и акцентный цвет.
- По умолчанию подключается к нашим серверам `hbbs`/`hbbr` с нашим ключом
  сервера.
- Вход в учётную запись и адресная книга работают через наш сервер API, а не
  через публичный сервер RustDesk.
- Новую версию проверяет на www.armilen.ru и по умолчанию обновляется сам. В
  RustDesk автообновление выключено; здесь его отключает галка «Auto update»
  в настройках.
- Ссылка на политику конфиденциальности ведёт на
  https://www.armilen.ru/legal/armdesk-privacy.

Всё остальное это код RustDesk.

## Версии

Номер версии читается как `<версия RustDesk>-<сборка ArmDesk>`: `1.5.0-1` это
первая сборка ArmDesk на основе RustDesk 1.5.0. Новые версии RustDesk
вливаются по мере выхода.

## Сборка

Собирается так же, как RustDesk: порядок описан в его
[README](https://github.com/rustdesk/rustdesk#readme). Сборки для релизов
делает GitHub Actions в этом репозитории.

## Лицензия

AGPL-3.0, как у RustDesk: текст в файле [LICENCE](LICENCE). Исходный код
каждой выпущенной сборки лежит в этом репозитории.
